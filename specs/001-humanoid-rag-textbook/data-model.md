# Data Model

This document defines the key data entities for the Humanoid Robotics Textbook and RAG Chatbot feature.

## 1. Chapter

Represents a single chapter in the Docusaurus textbook.

| Field | Type | Description | Required |
| :--- | :--- | :--- | :--- |
| `id` | `string` | A unique identifier for the chapter (e.g., the file slug). | Yes |
| `title` | `string` | The title of the chapter. | Yes |
| `content` | `string` (Markdown) | The full Markdown content of the chapter, including text, diagrams, and code. | Yes |
| `order` | `integer` | The numerical order of the chapter in the textbook. | Yes |

## 2. RAG Corpus

Represents the collection of documents ingested by the Vertex AI RAG Service. This is a logical entity managed by Vertex AI.

| Field | Type | Description | Required |
| :--- | :--- | :--- | :--- |
| `corpusId` | `string` | The unique ID provided by Vertex AI for the RAG corpus. | Yes |
| `displayName` | `string` | A human-readable name for the corpus. | Yes |

## 3. RAG Document / Chunk

Represents a single document (or chunk) within the Vertex AI RAG Corpus. The chunking is handled by the service.

| Field | Type | Description | Required |
| :--- | :--- | :--- | :--- |
| `documentId`| `string` | The unique ID provided by Vertex AI for the ingested document. | Yes |
| `displayName` | `string` | The name of the file or source of the document. | Yes |
| `content` | `string` | The text content of the chunk. | Yes |
| `embedding` | `vector` | The numerical vector embedding of the content (managed internally by Vertex AI). | Yes |

## 4. User Query

Represents a query sent from the user via the ChatKit UI.

| Field | Type | Description | Required |
| :--- | :--- | :--- | :--- |
| `queryText` | `string` | The text of the user's question. | Yes |
| `sessionId` | `string` | A unique identifier for the user's chat session, used for context. | No |

## 5. Chatbot Response

Represents the response generated by the RAG pipeline.

| Field | Type | Description | Required |
| :--- | :--- | :--- | :--- |
| `responseText` | `string` | The generated text answer. | Yes |
| `retrievedContext` | `array<RAG Document>` | The list of source chunks used to generate the answer (for citation/verification). | No |
