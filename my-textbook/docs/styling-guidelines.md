# Styling Guidelines for Black & Green Theme

This document outlines the styling guidelines for the black and green theme implemented in the Docusaurus textbook.

## Color Palette

- **Background**: `#0b0f14` (Dark background)
- **Text**: `#e6f4ea` (Light green text)
- **Primary Accent**: `#00c853` (Green for links, buttons, highlights)
- **Secondary**: `#1a232a` (Dark gray for code blocks, borders)

## Typography

- Headings use the same text color as body text for consistency
- H1 has a green bottom border for visual hierarchy
- H2 has a subtle gray bottom border
- H3 and H4 maintain consistent styling

## Code Blocks

- Background: `#1a232a`
- Text: `#e6f4ea`
- Inline code has a subtle border for distinction
- Pre-formatted blocks have rounded corners and padding

## Admonitions

- Note and Tip: Green left border (`#00c853`)
- Caution: Orange left border (`#ff8a65`)
- Danger: Red left border (`#ff5252`)

## Responsive Design

All styling is responsive and adapts to different screen sizes. The theme maintains WCAG AA contrast compliance across all devices.
